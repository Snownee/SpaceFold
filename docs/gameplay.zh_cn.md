# 空间折叠（Space Fold）玩法说明

## 一句话概括

把一座庞大的机器或农场，在模组提供的专属**碎片**里搭好、跑一遍并测出稳定的
输入 / 输出速率，然后把它"折叠"成一枚**碎片引擎**。碎片引擎不再需要摆出真实结构，
而是按测得的速率持续吞吐资源；**划片炉**则用材料批量生产这些碎片引擎。

## 方块与物品

| 名称 | 说明 |
| --- | --- |
| 时空锚 Spacetime Anchor | 核心方块。放在正常世界时用于分配碎片并传送进入；也作为"测试"的入口。 |
| 界面膜 Interface Membrane | 碎片的边界（外壳），由模组自动生成，禁止破坏。 |
| 越界端口 Boundary Port | 贴在膜上的"端口"，是碎片内机器与外界交换物品 / 流体 / 能量的唯一通道。 |
| 碎片引擎 Shard Engine | 被折叠后的机器，按测试结果里的速率持续输入与产出。 |
| 划片炉 Shard Carver | 读取一个模板（带结果的碎片引擎 / 时空锚），消耗材料与能量，产出新的碎片引擎。 |
| 时空刻针 Spacetime Awl | 手持右键，在**界面膜**与**越界端口**之间来回切换。 |

## 基本流程

### 1. 取片

在正常世界放置一个**时空锚**，右键打开界面，点击"传送"。
模组会为你分配一片 11×11×11 的碎片，把你送到碎片外，并将你的活动范围
限制在碎片范围内；碎片内可以自由飞行，创造模式不受限制。

### 2. 搭建机器

在碎片里搭好你的机器。凡是需要与外界交换的资源，都要用**时空刻针**把对应膜面
改成**越界端口**：

- 碎片的六个面，每个面最多只能有 **1 个**越界端口，否则测试会报错。
- 碎片内部（除时空锚外）不允许存在"带内容"的方块实体，例如装着东西的箱子、
  存有缓存或能量的机器等——碎片必须能被完整清空、复制。
- 不确定时可用命令 `/spacefold check_room` 检查：合法会列出材料清单，
  不合法会高亮问题方块。

越界端口就是折叠后机器的"端口"。你在正常世界放置的那个时空锚，六个面分别对应
碎片里六个朝向的越界端口：在时空锚的某一面接入资源，就等于在碎片对应面开了口。

### 3. 测试

右键时空锚，点击"测试"——碎片里的那个，或正常世界里的那个都可以。模组会：

1. 做合法性检查（端口数量、内部方块实体能否清空）。
2. 把整片碎片原样复制到一处隔离空间运行。
3. 以加速倍率（默认 10 倍）运行 `trial.duration` 秒（默认 15 秒）。
   期间你在安全的旁观视角观看，无法破坏方块。
4. 统计通过越界端口进出的物品 / 流体 / 能量。
5. 结束后结算：**输出速率 − 输入速率 = 净产出**，同时记录碎片的**材料清单**
   （每个方块对应的物品与数量）。

只要有资源输入即可，并不要求是一座完整的产线。

### 4. 结果判定

**成功**需同时满足：

- 净产出达到阈值：物品 ≥ 5/s，或流体 ≥ 100 mB/s，或能量 ≥ 10000 E/s（任一即可）；
- 资源种类不超过上限（默认输入、输出各 9 种）；
- 碎片内容没有被机器改动。

成功时结果会记录在这个时空锚物品上，可以随时空锚一起带走 / 掉落，
用于后续制作碎片引擎。

**失败**的常见原因与提示：

- 碎片内存在无法清空的方块（测试开始前就会直接拒绝）；
- 方块发生了变化（机器改动了碎片）；
- 输出速率过低（有进有出但净产出为负，也按此项处理）；
- 没有净产出；
- 资源种类过多。

## 碎片引擎

用带结果的碎片引擎物品放置，或由划片炉产出，它就会按结果中的速率工作：

- **朝向**决定输出面，其余面作为输入面。
- 自动**节流**：初始 0%，每秒上升 `rampUpPercent`（默认 +10%），
  一旦缺料或输出堵塞则每秒下降 `rampDownPercent`（默认 −15%）；没有输入需求时直接拉满。
- 拥有物品 / 流体 / 能量缓冲，缓冲满或前方堵塞会降速。
- 会把产物自动推给前方的容器 / 机器。
- 碎片引擎运行时不再消耗材料，只按结果中的速率吞吐。

手持碎片引擎物品 **Shift + 右键**：

- 创造模式且有 OP 权限：打开配置界面，可手动编辑输入 / 输出 / 材料
  （物品数量 = 每秒速率），用于自定义配方或调试。
- 普通玩家：查看该碎片引擎的材料清单。

## 划片炉

- 把**模板**（带结果的碎片引擎或时空锚）放进模板槽。
- 按材料清单提供材料，并提供能量。
- 每生产 1 个碎片引擎消耗清单数量 × `carver.outputPerCraft` 的材料与
  `carver.energyPerCraft` 能量，耗时 `carver.durationTicks`（默认 100 tick）。
- 材料随进度逐渐消耗，界面可查看材料进度。

## 保护与限制

- 非创造玩家只能在分配给自己的碎片里放置方块，且不能破坏碎片外壳。
- 测试期间为旁观模式，不能破坏方块；测试结束后恢复原游戏模式。
- 玩家活动会被限制在碎片范围内（`containment.confine` 可关闭）。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/spacefold check_room` | 检查当前所在碎片是否合法；合法则列出材料清单，不合法则高亮问题方块。 |
